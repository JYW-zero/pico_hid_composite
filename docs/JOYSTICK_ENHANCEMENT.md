# 摇杆驱动增强文档

## 一、概述

本项目使用 **PS2 双轴摇杆**（ADC 读取），采用双核架构：
- **Core1**：ADC 读取 + 信号处理（校准、死区、曲线）+ 共享数据写入
- **Core0**：HID 报告生成 + 配置管理 + 上位机接口

增强功能：
1. **中心点自动校准**：通过上位机命令触发，采样取平均值
2. **死区处理**：可配置死区，死区内输出 0（漂移抑制）
3. **灵敏度曲线**：线性、指数、对数三种曲线
4. **轴反转**：X/Y 轴独立反转
5. **灵敏度调节**：定点数灵敏度（1.0=1000）

**优化功能（v2）**：
6. **校准数据 Flash 持久化**：校准后自动保存到配置，重启后保留
7. **校准状态 GET_REPORT**：上位机可查询校准状态和中心点
8. **圆形死区**：使用欧几里得距离判断，避免方形死区的对角问题
9. **自动漂移补偿**：长时间微小输出自动微调中心点，防止漂移

## 二、硬件架构

### 2.1 PS2 摇杆

```
RP2350 ADC0 (GPIO26) ──→ 摇杆 X 轴
RP2350 ADC1 (GPIO27) ──→ 摇杆 Y 轴
RP2350 GPIO  ──→ 摇杆按键（上拉输入，低电平有效）
```

- ADC 分辨率：12 位（0-4095）
- 读取方式：4 次采样取平均，通道切换后丢弃第一次采样
- 扫描周期：10ms（100Hz）

### 2.2 双核架构

```
┌─────────────────────────────────────────────────────┐
│  Core1 (硬件扫描)                                    │
│  ┌──────────┐    ┌──────────────┐    ┌──────────┐ │
│  │ ADC 读取 │───→│ 摇杆处理器   │───→│ 共享数据 │ │
│  │ (4次平均)│    │ (校准/死区/  │    │ (自旋锁) │ │
│  │          │    │  曲线/反转)  │    │          │ │
│  └──────────┘    └──────────────┘    └──────────┘ │
└──────────────────────────┬──────────────────────────┘
                           │ 共享数据
┌──────────────────────────▼──────────────────────────┐
│  Core0 (业务处理)                                    │
│  ┌──────────┐    ┌──────────────┐    ┌──────────┐ │
│  │ HID 报告 │───→│ 配置管理     │───→│ 上位机   │ │
│  │ 生成     │    │ (死区/灵敏度/│    │ 接口     │ │
│  │          │    │  反转/曲线)  │    │          │ │
│  └──────────┘    └──────────────┘    └──────────┘ │
└─────────────────────────────────────────────────────┘
```

## 三、摇杆信号处理器（middleware/joystick_processor）

### 3.1 处理流程

```
原始 ADC 值 (0-4095)
    │
    ▼
1. 减去中心点（校准后的 center_x/y）
    │
    ▼
2. 死区处理（|x| < deadzone → x=0）
    │
    ▼
3. 缩放至 -127~127（根据中心点到边缘的距离）
    │
    ▼
4. 应用灵敏度（定点数，1.0=1000）
    │
    ▼
5. 应用灵敏度曲线（线性/指数/对数）
    │
    ▼
6. 限制范围（-127~127）
    │
    ▼
7. 轴反转（X/Y 独立）
    │
    ▼
输出结果 (-127~127)
```

### 3.2 中心点校准

**校准流程**：
1. 上位机发送 `CMD_JOYSTICK_CALIBRATE`（0x0E）命令
2. Core0 通过共享数据触发 Core1 开始校准
3. Core1 在摇杆任务中持续采样，取平均值作为中心点
4. 校准完成后，中心点保存在摇杆处理器的静态变量中

**校准参数**：
- 采样次数：50-200 次（默认 50）
- 采样周期：10ms（摇杆任务周期）
- 校准时间：0.5s - 2s

**注意**：当前校准数据仅保存在内存中，重启后恢复默认中心点（2048）。后续版本可增加 Flash 持久化。

### 3.3 死区处理

**死区定义**：以中心点为圆心，半径为 `deadzone` 的圆形区域（实际为方形，X/Y 独立判断）。

**死区内行为**：
- X 和 Y 都输出 0
- `in_deadzone` 标志为 true
- 用于漂移抑制：摇杆松开后，微小的 ADC 波动不会产生输出

**配置**：
- `joystick_deadzone`：死区大小（ADC 原始值，0-4095）
- 默认值：100（约 2.4% 的范围）

### 3.4 灵敏度曲线

| 曲线类型 | 值 | 公式 | 特点 |
|---------|---|------|------|
| 线性 | 0 | f(x) = x | 默认，响应均匀 |
| 指数 | 1 | f(x) = 1-(1-x)² | 小值更灵敏，大值更平缓 |
| 对数 | 2 | f(x) = √x | 小值更平缓，大值更灵敏 |

**曲线应用**：
1. 输入值归一化到 0.0~1.0
2. 应用曲线公式
3. 反归一化到 0~127

**配置**：
- 使用 `device_config_t.reserved2[0]` 存储曲线类型
- 上位机通过配置块设置

### 3.5 灵敏度调节

**灵敏度定义**：定点数，1.0 = 1000。
- 灵敏度 = 500 → 输出减半（更平缓）
- 灵敏度 = 1000 → 正常输出
- 灵敏度 = 2000 → 输出加倍（更灵敏，会被截断到 127）

**配置**：
- `joystick_sensitivity`：灵敏度（定点数，1.0=1000）
- 默认值：1000

### 3.6 轴反转

**配置**：
- `joystick_invert_x`：X 轴反转（0=正常，1=反转）
- `joystick_invert_y`：Y 轴反转（0=正常，1=反转）
- 默认值：X=0（正常），Y=1（反转，因为物理方向与 HID 相反）

## 四、上位机接口

### 4.1 HID 命令

| 命令 | Report ID | 值 | 说明 |
|------|-----------|---|------|
| CMD_JOYSTICK_CALIBRATE | 7 (Control) | 0x0E | 触发摇杆中心点校准 |
| CMD_SET_JOYSTICK_DZ_RT | 7 (Control) | 0x0C | 实时设置摇杆死区（不写 Flash） |

**CMD_JOYSTICK_CALIBRATE 数据格式**：
```
byte[0] = 命令码 (0x0E)
byte[1-2] = 采样次数（小端，默认 50，范围 50-200）
```

**校准状态查询**：
- 通过 `shared_hw_get_joystick_calibration_state()` 获取
- 0=空闲，1=校准中，2=完成
- 后续可增加 GET_REPORT 接口返回校准状态和中心点

### 4.2 配置参数

通过配置块（Report ID 5/8/9）设置：

| 字段 | 偏移 | 大小 | 说明 |
|------|------|------|------|
| joystick_deadzone | 配置结构偏移 84 | 2 字节 | 死区（ADC 原始值） |
| joystick_invert_x | 配置结构偏移 92 | 1 字节 | X 轴反转 |
| joystick_invert_y | 配置结构偏移 93 | 1 字节 | Y 轴反转 |
| joystick_sensitivity | 配置结构偏移 96 | 2 字节 | 灵敏度（定点数） |
| reserved2[0] | 配置结构偏移 98 | 1 字节 | 曲线类型 |

1. 发送校准命令，保持摇杆在中心位置
2. 等待校准完成（约 0.5s）

## 七、后续优化

1. **校准数据 Flash 持久化**：将中心点保存到 Flash，重启后保留
2. **校准状态 GET_REPORT**：增加 GET_REPORT 接口返回校准状态和中心点
3. **自动漂移补偿**：长时间检测到微小输出时自动微调中心点
4. **圆形死区**：当前为方形死区（X/Y 独立），可改为圆形死区
5. **加速度曲线**：根据摇杆移动速度动态调整灵敏度

## 八、优化功能详细说明（v2）

### 8.1 校准数据 Flash 持久化

**实现方式**：
- 配置版本升级到 v5，增加 `joystick_center_x`、`joystick_center_y`、`joystick_calibrated` 字段
- Core1 校准完成后，将校准数据写入共享数据并设置更新标志
- Core0 主循环检测到更新标志后，读取校准数据并保存到配置 Flash
- 启动时，Core0 从配置读取校准数据，写入共享数据
- Core1 启动时从共享数据加载校准数据到摇杆处理器

**数据流**：
```
校准完成 → Core1 写入共享数据 → 设置更新标志
    ↓
Core0 主循环检测标志 → 读取共享数据 → config_save() → Flash
    ↓
重启 → Core0 从 Flash 读取 → 写入共享数据 → Core1 加载
```

### 8.2 校准状态 GET_REPORT

**Report ID**：23（`REPORT_ID_JOYSTICK_CALIB`）

**数据格式**（GET_REPORT 返回）：
| 字节 | 说明 |
|------|------|
| 0 | 校准状态（0=空闲,1=校准中,2=完成） |
| 1-2 | center_x（小端，ADC 值） |
| 3-4 | center_y（小端，ADC 值） |
| 5 | calibrated（0=未校准,1=已校准） |
| 6-7 | 死区值（小端，ADC 原始值） |
| 8-9 | 灵敏度（小端，定点数 1.0=1000） |

### 8.3 圆形死区

**原理**：
- 方形死区：X/Y 独立判断，对角方向死区更大（√2 倍）
- 圆形死区：使用欧几里得距离 `distance = sqrt(x² + y²)` 判断，各方向一致

**实现**：
1. 计算 `dist_sq = x² + y²`，`deadzone_sq = deadzone²`
2. 如果 `dist_sq < deadzone_sq`，在死区内，输出 0
3. 否则，按比例缩放：`scale = (distance - deadzone) / distance`，消除死区造成的台阶

**优点**：
- 更符合摇杆的物理特性（摇杆是圆形的）
- 对角方向的死区与正方向一致
- 死区边缘平滑过渡（无台阶）

### 8.4 自动漂移补偿

**原理**：
- 摇杆由于硬件特性，长时间使用后中心点可能会发生微小漂移
- 自动漂移补偿检测长时间微小输出，自动微调中心点，使输出变为 0

**实现**：
1. 检测输出是否在死区附近（小于死区的 1.5 倍）
2. 如果持续 100 次（1 秒@10ms），触发微调
3. 微调步长：每次 1 个 ADC 值，方向朝向当前输出
4. 最大微调限制：±50 个 ADC 值，避免中心点被偏移太多
5. 如果输出较大，重置计数器

**配置接口**：
- `joystick_processor_set_drift_compensation(bool)` — 启用/禁用
- `joystick_processor_get_drift_compensation()` — 获取状态
- `joystick_processor_reset_drift_compensation()` — 重置漂移状态

**注意**：
- 漂移微调是临时的，不保存到校准数据
- 重新校准后，漂移微调会被重置
- 默认启用，可通过接口禁用
