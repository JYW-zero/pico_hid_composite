## 快速参考

### 测试项目速查

**FCC Part 15B**：
- 传导发射（150kHz-30MHz）
- 辐射发射（30MHz-1GHz，1GHz-6GHz）

**CE EMC**：
- 发射：传导发射、辐射发射（同 FCC）
- 抗扰度：ESD、辐射抗扰、EFT、浪涌、传导抗扰、工频磁场

**RoHS**：
- 10 项限制物质测试（Pb, Hg, Cd, Cr(VI), PBB, PBDE, DEHP, DBP, BBP, DIBP）

### 关键限值

- **FCC Class B 传导**：56-46 dBμV（准峰值）
- **FCC Class B 辐射**：30-40 dBμV/m（准峰值，3 米法）
- **RoHS 限值**：Pb/Hg/Cr(VI)/PBB/PBDE/DEHP/DBP/BBP/DIBP ≤ 1000ppm，Cd ≤ 100ppm

## 注意事项

1. **提前准备**：建议在产品设计阶段就考虑 EMC，可大幅降低整改成本
2. **样品数量**：EMC 测试需 2-3 台，RoHS 测试需 1-2 台（拆解后无法使用）
3. **文档保存**：CE 技术文档需保存至少 10 年
4. **供应链管控**：RoHS 合规需要持续管控供应商，建议每年审核
5. **标志规范**：CE 标志高度至少 5mm，比例必须正确
