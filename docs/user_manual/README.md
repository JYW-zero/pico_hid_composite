本目录包含指动 HID 复合设备的用户手册，提供中文和英文两个版本。

| 语言 | 文件 | 说明 |

| English | [User_Manual_en-US.md](./User_Manual_en-US.md) | English User Manual |

## 手册内容

用户手册包含以下章节：

1. **快速开始 / Quick Start** - 开箱、连接、安装上位机
2. **设备介绍 / Device Overview** - 功能概览、硬件规格
3. **上位机安装 / Software Installation** - Windows/macOS/Linux 安装指南
4. **按键自定义 / Key Customization** - 单键修改、多层映射、批量编辑
5. **宏功能 / Macro Functions** - 录制、编辑、绑定、管理
6. **鼠标设置 / Mouse Settings** - DPI 设置、自定义 DPI、滚轮设置
7. **摇杆设置 / Joystick Settings** - 校准、死区、灵敏度曲线、方向反转
8. **编码器设置 / Encoder Settings** - 模式切换、旋转加速度、去抖
9. **配置管理 / Configuration Management** - 保存、恢复默认、导入导出、预设
10. **固件升级 / Firmware Update** - 检查版本、升级方法、失败恢复
11. **常见问题 / FAQ** - 连接、按键、宏、鼠标、摇杆、固件、上位机问题
12. **技术规格 / Technical Specifications** - 硬件、软件、USB 描述符、兼容性
