## 1. 快速开始

### 1.1 包装清单

- [ ] 指动 HID 复合设备 × 1
- [ ] USB Type-C 数据线 × 1
- [ ] 本用户手册 × 1

> 📷 *[配图：产品包装清单照片]*

### 1.2 连接设备

1. 使用 USB Type-C 数据线将设备连接到电脑
2. 等待电脑自动识别设备（Windows/macOS/Linux 均免驱）
3. 设备指示灯亮起表示连接成功

> 📷 *[配图：设备连接示意图]*

### 1.3 验证连接

**Windows**：
- 打开「设备管理器」→「人体学输入设备」
- 应能看到「HID 符合的设备」和「符合 HID 标准的供应商定义的设备」

**macOS**：
- 打开「系统信息」→「USB」
- 应能看到「指动 HID 复合设备」

**Linux**：
- 终端运行 `lsusb`
- 应能看到 VID 0x1209 / PID 0x4004 的设备

### 1.4 安装上位机

1. 访问项目 GitHub 仓库下载最新版本上位机
2. Windows 用户下载 `pc-tool-windows-self-contained.zip`
3. 解压后运行 `HidConfigTool.App.exe`
4. 上位机将自动识别已连接的设备

> 📷 *[配图：上位机主界面截图]*

## 2. 设备介绍

### 2.1 功能概览

指动 HID 复合设备是一款高度可配置的输入设备，支持：

- ✅ **全键自定义**：每个按键可映射为任意键盘按键、鼠标按键、媒体键或宏
- ✅ **多层按键映射**：支持 4 层按键映射，通过 Fn 键切换
- ✅ **宏录制**：支持按键序列、延迟、循环，可存储到 Flash
- ✅ **多档 DPI**：支持 4 档预设 DPI + 自定义 DPI，一键切换
- ✅ **摇杆校准**：支持死区调节、灵敏度曲线、方向反转
- ✅ **编码器**：支持音量、滚动、缩放、亮度等多种模式
- ✅ **配置导入/导出**：配置可保存为文件，便于备份和分享
- ✅ **固件升级**：通过 USB DFU 模式在线升级固件

> 📷 *[配图：设备功能示意图]*

### 2.2 硬件规格

| 项目 | 规格 |
|-----|------|
| 主控芯片 | RP2350（双核 ARM Cortex-M33） |
| 按键数量 | 64 键（可配置） |
| 摇杆 | 双通道模拟摇杆 |
| 编码器 | 旋转编码器（带按键） |
| 鼠标传感器 | 光学传感器（最高 26000 DPI） |
| 接口 | USB Type-C |
| 兼容系统 | Windows 10/11、macOS 12+、Linux |
| 驱动 | 免驱（标准 HID 设备） |

## 3. 上位机安装

### 3.1 系统要求

| 系统 | 最低版本 | 推荐版本 |
|-----|---------|---------|
| Windows | Windows 10 1809 | Windows 11 |
| macOS | macOS 12 Monterey | macOS 14 Sonoma |
| Linux | Ubuntu 20.04 | Ubuntu 22.04+ |

### 3.2 Windows 安装

1. 从 GitHub Releases 下载 `pc-tool-windows-self-contained.zip`
2. 解压到任意目录（如 `C:\Program Files\HidConfigTool`）
3. 右键 `HidConfigTool.App.exe` →「发送到」→「桌面快捷方式」
4. 双击快捷方式启动上位机

> 💡 **提示**：自包含版本已包含 .NET 运行时，无需额外安装。

### 3.3 macOS 安装

1. 从 GitHub Releases 下载 `pc-tool-macos.zip`
2. 解压后将 `HidConfigTool.app` 拖入「应用程序」文件夹
3. 首次运行时，右键点击应用 →「打开」→ 确认打开
4. 后续可直接从启动台打开

### 3.4 Linux 安装

```bash
# 下载并解压
wget https://github.com/JYW-zero/pico_hid_composite/releases/latest/download/pc-tool-linux.zip
unzip pc-tool-linux.zip -d HidConfigTool
cd HidConfigTool

# 添加执行权限
chmod +x HidConfigTool

# 运行
./HidConfigTool
```

> ⚠️ **注意**：Linux 用户可能需要配置 udev 规则以获得 USB 设备访问权限。

> 📷 *[配图：上位机主界面标注图]*

## 4. 按键自定义

### 4.1 进入按键设置

1. 连接设备并打开上位机
2. 点击左侧导航栏的「按键设置」
3. 界面将显示设备的按键布局

> 📷 *[配图：按键设置界面截图]*

### 4.2 修改单个按键

1. 在按键布局图中点击要修改的按键
2. 右侧弹出按键配置面板
3. 选择按键功能类型：
   - **键盘按键**：映射为标准键盘按键（如 A、B、Ctrl、Shift 等）
   - **鼠标按键**：映射为鼠标左键、右键、中键等
   - **媒体键**：映射为播放/暂停、音量加减、下一曲等
   - **宏**：映射为已录制的宏
   - **层切换**：映射为切换到其他按键层
   - **无功能**：禁用该按键

4. 选择具体的按键值
5. 点击「应用」保存修改

### 4.3 多层按键映射

设备支持 4 层按键映射（Layer 0 - Layer 3）：

- **Layer 0**：默认层，正常使用
- **Layer 1**：Fn 层，按住 Fn 键时激活
- **Layer 2**：扩展层，可通过组合键切换
- **Layer 3**：游戏层，可针对游戏优化

**切换层的方法**：
1. 将某个按键设置为「层切换」功能
2. 选择目标层（Layer 1/2/3）
3. 选择切换模式：
   - **按住切换**：按住该键时临时切换，松开返回
   - **锁定切换**：按一下锁定到目标层，再按一下返回

### 4.4 批量修改

1. 点击「批量编辑」按钮
2. 框选多个按键（或按住 Ctrl 点选）
3. 在右侧面板设置统一的功能
4. 点击「应用到选中按键」

### 4.5 恢复单个按键默认

1. 右键点击要恢复的按键
2. 选择「恢复默认」
3. 确认操作

## 5. 宏功能

### 5.1 宏介绍

宏是一系列预定义的按键操作序列，可以一键触发。支持：

- 按键按下/释放
- 延迟等待
- 循环执行
- 鼠标点击
- 媒体键操作

### 5.2 录制新宏

1. 点击左侧导航栏的「宏管理」
2. 点击「新建宏」按钮
3. 输入宏名称（如「连招1」）
4. 点击「开始录制」
5. 在设备上按下要录制的按键序列
6. 点击「停止录制」
7. （可选）在时间轴上调整每个动作的延迟
8. 点击「保存」

> 📷 *[配图：宏录制界面截图]*

### 5.3 手动编辑宏

1. 在宏列表中选择要编辑的宏
2. 点击「编辑」按钮
3. 在动作列表中：
   - **添加动作**：点击「+」按钮，选择动作类型
   - **修改动作**：双击动作行，修改参数
   - **删除动作**：选中动作，点击「-」按钮
   - **调整顺序**：拖拽动作行上下移动
4. 设置循环次数（1-999 次，或无限循环）
5. 点击「保存」

### 5.4 宏动作类型

| 动作类型 | 说明 | 参数 |
|---------|------|------|
| 按键按下 | 按下指定按键 | 按键码 |
| 按键释放 | 释放指定按键 | 按键码 |
| 按键点击 | 按下并释放 | 按键码、按下时长 |
| 鼠标按下 | 按下鼠标按键 | 鼠标按键（左/右/中） |
| 鼠标释放 | 释放鼠标按键 | 鼠标按键 |
| 鼠标点击 | 点击鼠标按键 | 鼠标按键、点击时长 |
| 延迟 | 等待指定时间 | 延迟毫秒数（1-10000ms） |
| 滚轮 | 滚动鼠标滚轮 | 滚动方向、滚动量 |

### 5.5 将宏绑定到按键

1. 进入「按键设置」
2. 点击要绑定宏的按键
3. 在功能类型中选择「宏」
4. 从下拉列表中选择要绑定的宏
5. 选择触发方式：
   - **按下触发**：按下按键时执行宏
   - **释放触发**：松开按键时执行宏
   - **切换触发**：按一下开始，再按一下停止（适用于循环宏）
6. 点击「应用」

### 5.6 管理宏

- **重命名**：右键宏 →「重命名」
- **删除**：右键宏 →「删除」
- **复制**：右键宏 →「复制」
- **导出**：选中宏 →「导出」，保存为 `.macro` 文件
- **导入**：点击「导入」，选择 `.macro` 文件

### 5.7 宏使用技巧

1. **游戏连招**：将复杂的连招录制为宏，一键释放
2. **办公快捷**：将常用的快捷键组合（如 Ctrl+C、Ctrl+V）录制为宏
3. **输入文本**：通过宏快速输入常用文本（如邮箱地址）
4. **循环操作**：设置无限循环宏，用于重复操作（如自动点击）

> ⚠️ **注意**：在网络游戏中使用宏可能违反游戏规则，请谨慎使用。

## 6. 鼠标设置

### 6.1 DPI 设置

DPI（Dots Per Inch）决定鼠标移动的灵敏度。DPI 越高，光标移动越快。

**预设 DPI 档位**：

| 档位 | DPI 值 | 适用场景 |
|-----|--------|---------|
| 1 | 400 | 精确操作、FPS 游戏 |
| 2 | 800 | 日常办公、通用 |
| 3 | 1600 | 高分辨率屏幕 |
| 4 | 3200 | 快速移动、MOBA 游戏 |

**修改 DPI 档位**：
1. 进入「鼠标设置」
2. 在「DPI 档位」区域点击要修改的档位
3. 输入新的 DPI 值（100-26000）
4. 点击「应用」

**切换 DPI**：
- **按键切换**：将某个按键设置为「DPI 切换」，按一下循环切换档位
- **上位机切换**：在鼠标设置界面点击对应档位
- **实时调节**：拖动 DPI 滑块实时调节（仅当前生效，不保存）

> 📷 *[配图：鼠标 DPI 设置界面截图]*

### 6.2 自定义 DPI

如果预设档位不满足需求，可以使用自定义 DPI：

1. 在 DPI 设置中选择「自定义」
2. 输入具体的 DPI 值（100-26000）
3. 点击「应用」
4. 设备将立即使用新的 DPI

> 💡 **提示**：建议先在游戏或软件中测试不同 DPI，找到最适合自己的值。

### 6.3 鼠标按键映射

设备上的按键可以映射为鼠标功能：

1. 进入「按键设置」
2. 点击要修改的按键
3. 功能类型选择「鼠标按键」
4. 选择具体的鼠标按键：
   - 鼠标左键
   - 鼠标右键
   - 鼠标中键
   - 鼠标侧键 1（后退）
   - 鼠标侧键 2（前进）
5. 点击「应用」

### 6.4 滚轮设置

1. 进入「鼠标设置」→「滚轮」
2. 设置滚轮方向：
   - **正常**：向上滚动 = 向上翻页
   - **反转**：向上滚动 = 向下翻页
3. 设置滚轮速度（1-10 档）
4. 点击「应用」

## 7. 摇杆设置

### 7.1 摇杆校准

首次使用或更换设备后，建议进行摇杆校准：

1. 进入「摇杆设置」
2. 点击「开始校准」
3. 按照提示操作：
   - 第一步：松开摇杆，等待 2 秒（校准中心点）
   - 第二步：将摇杆推到四个极限位置（上、下、左、右）
   - 第三步：松开摇杆，等待校准完成
4. 校准完成后，界面将显示校准结果

> 📷 *[配图：摇杆校准界面截图]*

### 7.2 死区设置

死区是指摇杆中心附近不响应的区域。增大死区可以防止摇杆漂移，但会降低灵敏度。

1. 进入「摇杆设置」→「死区」
2. 拖动 X 轴死区滑块（0-4095）
3. 拖动 Y 轴死区滑块（0-4095）
4. 实时观察摇杆状态图，死区区域显示为灰色
5. 点击「应用」保存

> 💡 **建议**：
> - 日常使用：死区设为 5-10%
> - 游戏（精确操作）：死区设为 2-5%
> - 摇杆有漂移：适当增大死区

### 7.3 灵敏度曲线

灵敏度曲线决定摇杆输入到光标的映射关系：

1. 进入「摇杆设置」→「灵敏度」
2. 选择曲线类型：
   - **线性**：输入与输出成正比（默认）
   - **指数**：小输入时慢，大输入时快（适合游戏）
   - **对数**：小输入时快，大输入时慢（适合精确操作）
   - **自定义**：手动调整曲线参数
3. 拖动灵敏度滑块（50%-200%）
4. 实时观察曲线预览
5. 点击「应用」

### 7.4 方向反转

1. 进入「摇杆设置」→「方向」
2. 勾选「反转 X 轴」可左右反转
3. 勾选「反转 Y 轴」可上下反转
4. 点击「应用」

> 💡 **提示**：飞行模拟游戏通常需要反转 Y 轴（推拉摇杆控制俯仰）。

### 7.5 摇杆模式

摇杆可以工作在不同模式：

1. 进入「摇杆设置」→「模式」
2. 选择工作模式：
   - **鼠标模式**：摇杆控制鼠标光标移动
   - **游戏手柄模式**：摇杆作为游戏手柄的左摇杆
   - **键盘模式**：摇杆映射为方向键（WASD 或方向键）
   - **滚轮模式**：摇杆控制鼠标滚轮
3. 点击「应用」

## 8. 编码器设置

### 8.1 编码器模式

旋转编码器支持多种工作模式：

| 模式 | 功能 | 适用场景 |
|-----|------|---------|
| 音量 | 旋转调节系统音量，按下静音 | 日常使用 |
| 滚动 | 旋转控制页面滚动，按下中键 | 浏览网页/文档 |
| 缩放 | 旋转控制缩放，按下重置 | 设计/绘图 |
| 亮度 | 旋转调节屏幕亮度 | 笔记本电脑 |
| 自定义 | 旋转映射为自定义按键 | 高级用户 |

**切换模式**：
1. 进入「编码器设置」
2. 从「模式」下拉列表中选择目标模式
3. 点击「应用」
4. 编码器立即切换到新模式

> 📷 *[配图：编码器设置界面截图]*

### 8.2 旋转加速度

开启旋转加速度后，快速旋转编码器会产生更大的步进值：

1. 进入「编码器设置」→「加速度」
2. 勾选「启用旋转加速度」
3. 设置加速度参数：
   - **基础步进**：慢速旋转时每格的步进值（1-10）
   - **最大步进**：快速旋转时每格的最大步进值（1-100）
   - **加速度曲线**：旋转速度到步进值的映射曲线
4. 点击「应用」

> 💡 **建议**：
> - 音量模式：基础步进 2，最大步进 10
> - 滚动模式：基础步进 3，最大步进 20
> - 缩放模式：基础步进 1，最大步进 5

### 8.3 编码器按键

编码器按下时可以触发不同功能：

1. 进入「编码器设置」→「按键」
2. 选择按下功能：
   - **模式默认**：使用当前模式的默认按键功能
   - **鼠标中键**：按下触发鼠标中键
   - **播放/暂停**：按下触发媒体播放/暂停
   - **自定义按键**：按下触发任意键盘按键
   - **切换模式**：按下循环切换编码器模式
3. 点击「应用」

### 8.4 去抖设置

如果编码器出现误触发或跳动，可以调整去抖参数：

1. 进入「编码器设置」→「高级」
2. 设置去抖时间（1-10ms，默认 3ms）
3. 设置最小有效旋转间隔（1-50ms，默认 5ms）
4. 点击「应用」

> ⚠️ **注意**：过大的去抖参数会降低编码器响应速度，建议保持默认值。

## 9. 配置管理

### 9.1 保存配置

修改设置后，需要保存到设备的 Flash 中：

1. 完成所有设置修改
2. 点击上位机右下角的「保存配置」按钮
3. 等待保存完成（通常 1-2 秒）
4. 设备指示灯闪烁表示保存成功

> 💡 **提示**：配置保存在设备的 Flash 中，断电不会丢失。

### 9.2 恢复出厂设置

如果配置混乱或忘记修改内容，可以恢复出厂设置：

**方法一：通过上位机**
1. 进入「配置管理」→「恢复默认」
2. 点击「恢复出厂设置」
3. 在确认对话框中点击「确定」
4. 设备将自动重启并恢复默认配置

**方法二：通过组合键**
1. 按住 `Fn + Esc` 键
2. 保持按住 3 秒
3. 设备指示灯快速闪烁表示恢复成功
4. 松开按键，设备自动重启

> ⚠️ **警告**：恢复出厂设置将清除所有自定义配置，包括按键映射、宏、DPI 设置等。操作前请先备份配置。

### 9.3 导出配置

将当前配置保存为文件，便于备份或分享：

1. 进入「配置管理」→「导出」
2. 选择导出格式：
   - **JSON 格式**（`.json`）：可读，可手动编辑
   - **二进制格式**（`.bin`）：紧凑，占用空间小
   - **配置文件**（`.hidcfg`）：专用格式，包含完整配置
3. 选择保存位置和文件名
4. 点击「导出」

### 9.4 导入配置

从配置文件恢复设置：

1. 进入「配置管理」→「导入」
2. 点击「选择文件」，选择配置文件（`.json`/`.bin`/`.hidcfg`）
3. 上位机将显示配置预览（版本、按键数量、宏数量等）
4. 点击「导入」
5. 配置将写入设备并立即生效

> ⚠️ **注意**：
> - 导入配置将覆盖当前所有设置
> - 不同版本的配置文件可能不兼容，导入前请确认版本
> - 建议导入前先导出当前配置作为备份

### 9.5 配置预设

上位机内置了一些常用配置预设，可一键应用：

1. 进入「配置管理」→「预设」
2. 浏览预设列表：
   - **办公模式**：适合日常办公，DPI 800，编码器音量模式
   - **游戏模式**：适合 FPS 游戏，DPI 400，低死区
   - **设计模式**：适合绘图设计，高 DPI，编码器缩放模式
   - **媒体模式**：适合影音娱乐，编码器音量模式
3. 点击预设查看详情
4. 点击「应用」将预设写入设备

> 💡 **提示**：可以将自己的配置保存为自定义预设，方便快速切换。

## 10. 固件升级

### 10.1 检查固件版本

1. 连接设备并打开上位机
2. 查看设备状态栏的「固件版本」
3. 或进入「固件升级」页面查看当前版本

> 📷 *[配图：固件升级界面截图]*

### 10.2 下载最新固件

1. 访问项目 GitHub Releases 页面
2. 下载最新版本的固件文件（`.uf2` 格式）
3. 注意选择与设备硬件匹配的版本

### 10.3 通过上位机升级（推荐）

1. 进入「固件升级」页面
2. 点击「选择固件文件」，选择下载的 `.uf2` 文件
3. 上位机将显示固件信息（版本、大小、校验和）
4. 点击「开始升级」
5. 设备将自动进入 DFU 模式
6. 等待升级完成（进度条显示，通常 10-30 秒）
7. 升级完成后设备自动重启
8. 重启后验证固件版本

> ⚠️ **重要**：
> - 升级过程中**不要断开 USB 连接**
> - 升级过程中**不要关闭上位机**
> - 确保电脑不会进入休眠或睡眠模式
> - 建议使用稳定的 USB 接口（直连主板，避免使用 USB Hub）

### 10.4 通过 UF2 手动升级

如果上位机升级失败，可以使用 UF2 方式手动升级：

1. 进入「固件升级」页面
2. 点击「进入 DFU 模式」
3. 设备将重启并以 USB 大容量存储设备模式出现（盘符如 `RPI-RP2`）
4. 将下载的 `.uf2` 文件复制到该盘符
5. 复制完成后设备自动重启并完成升级
6. 重新连接上位机验证版本

### 10.5 升级失败处理

如果升级失败，设备可能无法正常启动。不要担心，RP2350 有内置 Bootloader，可以恢复：

1. 断开设备 USB 连接
2. 按住设备上的 `BOOTSEL` 按键（或设备上的特定组合键）
3. 保持按住的同时连接 USB
4. 设备将以 UF2 模式出现
5. 重新复制固件文件
6. 等待升级完成

> 💡 **提示**：如果不确定哪个按键是 BOOTSEL，请查阅设备硬件手册或联系技术支持。

### 10.6 固件更新日志

每次固件更新后，建议查看更新日志了解新功能和修复：

1. 访问 GitHub Releases 页面
2. 查看对应版本的 Release Notes
3. 了解新功能、改进和已知问题

## 11. 常见问题

### 11.1 设备连接问题

**Q：设备连接电脑后没有反应？**

A：
1. 检查 USB 数据线是否支持数据传输（有些线只能充电）
2. 尝试更换 USB 接口（建议直连主板）
3. 尝试更换 USB 数据线
4. 在设备管理器中查看是否有未知设备
5. 重启电脑后重试

**Q：上位机显示「未检测到设备」？**

A：
1. 确认设备已通过 USB 连接到电脑
2. 确认设备指示灯亮起
3. 点击上位机的「刷新设备列表」按钮
4. 检查是否有其他程序占用了设备（如其他 HID 工具）
5. 重新插拔设备
6. 以管理员身份运行上位机

**Q：设备连接后又断开，反复重连？**

A：
1. 可能是 USB 接口供电不足，尝试更换接口
2. 可能是数据线接触不良，更换数据线
3. 检查设备是否有短路或硬件问题
4. 如果问题持续，请联系技术支持

### 11.2 按键问题

**Q：按键按下没有反应？**

A：
1. 检查该按键是否被设置为「无功能」
2. 检查当前按键层是否正确
3. 在「按键测试」页面测试按键是否能被识别
4. 如果按键测试也没反应，可能是硬件问题
5. 尝试恢复出厂设置

**Q：按键延迟或卡顿？**

A：
1. 检查是否开启了过多的宏或复杂功能
2. 检查 USB 连接是否稳定
3. 尝试降低报告率（如果支持）
4. 关闭其他占用 CPU 的程序
5. 更新到最新固件

**Q：按键映射不生效？**

A：
1. 确认修改后点击了「保存配置」
2. 确认选择了正确的按键层
3. 检查是否有其他配置覆盖了该按键
4. 重新插拔设备后重试
5. 恢复出厂设置后重新配置

### 11.3 宏问题

**Q：宏执行不完整或跳过某些动作？**

A：
1. 检查宏的延迟设置是否合理
2. 某些程序可能对快速按键无响应，适当增加延迟
3. 检查宏的循环设置
4. 重新录制宏

**Q：宏无法停止？**

A：
1. 如果是无限循环宏，按一下绑定的按键可以停止
2. 如果无法停止，断开设备 USB 连接
3. 检查宏的触发方式设置
4. 在上位机中删除或修改该宏

**Q：宏录制时没有记录到某些按键？**

A：
1. 确保录制时按键按下和释放都被检测到
2. 某些特殊按键（如 Fn 键）可能不会被录制
3. 尝试手动编辑宏，添加缺失的动作
4. 更新到最新固件

### 11.4 鼠标问题

**Q：光标移动不流畅或抖动？**

A：
1. 检查鼠标传感器表面是否干净
2. 使用合适的鼠标垫（避免反光或不均匀表面）
3. 调整 DPI 设置，过高的 DPI 可能放大抖动
4. 检查 USB 连接是否稳定
5. 更新到最新固件

**Q：DPI 切换不生效？**

A：
1. 确认 DPI 按键映射正确
2. 确认保存了配置
3. 在上位机中直接切换 DPI 测试
4. 检查是否有其他配置覆盖了 DPI 设置

**Q：滚轮不工作或反向？**

A：
1. 检查编码器模式设置
2. 在「编码器设置」中检查滚轮方向
3. 测试编码器硬件是否正常（旋转时上位机是否有响应）
4. 恢复出厂设置后重试

### 11.5 摇杆问题

**Q：摇杆有漂移（不操作时光标自己移动）？**

A：
1. 重新进行摇杆校准
2. 适当增大死区
3. 检查摇杆是否被卡住或有异物
4. 如果漂移严重，可能是硬件问题，联系技术支持

**Q：摇杆死区设置不生效？**

A：
1. 确认修改后点击了「应用」和「保存配置」
2. 在摇杆状态图中观察死区是否正确显示
3. 重新进行摇杆校准
4. 更新到最新固件

**Q：摇杆灵敏度太低或太高？**

A：
1. 调整灵敏度曲线和灵敏度百分比
2. 选择合适的曲线类型（线性/指数/对数）
3. 检查死区设置，过大的死区会降低灵敏度
4. 根据使用场景调整

### 11.6 固件升级问题

**Q：固件升级失败怎么办？**

A：
1. 不要断开设备连接
2. 等待 30 秒看是否自动恢复
3. 如果设备无响应，使用 UF2 方式手动恢复（见 10.4 节）
4. 检查下载的固件文件是否完整（校验 MD5）
5. 尝试使用其他 USB 接口或电脑

**Q：升级后设备无法启动？**

A：
1. 使用 BOOTSEL 按键进入 UF2 模式
2. 重新刷入固件
3. 如果仍然无法启动，可能是硬件问题
4. 联系技术支持

**Q：如何确认固件升级成功？**

A：
1. 设备正常重启并被电脑识别
2. 上位机显示新的固件版本号
3. 设备功能正常
4. 可以在上位机「关于」页面查看版本信息

### 11.7 上位机问题

**Q：上位机无法启动？**

A：
1. 确认下载了正确的版本（Windows/macOS/Linux）
2. Windows 用户：确认使用自包含版本或已安装 .NET 运行时
3. macOS 用户：首次运行需右键→打开，确认安全设置
4. Linux 用户：确认添加了执行权限
5. 检查系统是否满足最低要求

**Q：上位机界面显示异常或卡顿？**

A：
1. 确保使用最新版本上位机
2. 检查系统显示缩放设置（建议 100% 或 150%）
3. 关闭其他占用资源的程序
4. 更新显卡驱动
5. 尝试在兼容模式下运行

**Q：配置保存后重启设备又恢复原样？**

A：
1. 确认点击了「保存配置」而不是仅「应用」
2. 等待保存完成提示
3. 检查设备 Flash 是否有问题
4. 尝试恢复出厂设置后重新配置
5. 更新到最新固件
