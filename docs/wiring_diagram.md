# 硬件接线图 (Wiring Diagram)

本文档详细说明了 Pico 2 (RP2350) 与各外设的接线方式。

---

## 📋 总览

| 外设 | 接口 | 使用引脚数 | SPI 总线 |
|------|------|-----------|---------|
| 64键键盘矩阵 | SPI + 74HC165 级联 | 4 | SPI0 |
| PAW3395 鼠标传感器 | SPI + 中断 + 复位 | 6 | SPI1 |
| 双轴摇杆 | ADC + GPIO | 3 | - |
| 滚轮编码器 | GPIO | 3 | - |
| **合计** | - | **16** | - |

---

## 🔌 详细接线表

### 1. 64 键 SPI 键盘矩阵（74HC165 级联）

> 使用 8 片 74HC165 移位寄存器级联，实现 64 键并行输入转串行输出。

| Pico 2 引脚 | 引脚名称 | 连接至 | 说明 |
|------------|---------|--------|------|
| **GP16** | SPI0 MISO | 74HC165 QH (第8片) | 串行数据输入 |
| **GP17** | GPIO | 74HC165 PL (所有片) | 并行加载（片选） |
| **GP18** | SPI0 SCK | 74HC165 CLK (所有片) | 时钟信号 |
| **GP19** | SPI0 MOSI | (未使用，可悬空) | - |
| **3.3V** | 3.3V OUT | 74HC165 VCC | 电源 |
| **GND** | GND | 74HC165 GND | 地 |

**74HC165 级联方式：**
```
第1片 QH → 第2片 SER
第2片 QH → 第3片 SER
...
第7片 QH → 第8片 SER
第8片 QH → Pico GP16 (MISO)
```

**键盘矩阵连接：**
- 每片 74HC165 的 8 个并行输入（A-H）连接 8 个按键的一端
- 所有按键的另一端连接在一起（共地或共阳，根据矩阵设计）
- 具体按键布局请参考 `keymap.h`

**SPI 参数：**
- 波特率：100 KHz
- 模式：CPOL=0, CPHA=0 (Mode 0)
- CS 延时：5 μs

---

### 2. PAW3395 光学鼠标传感器

| Pico 2 引脚 | 引脚名称 | 连接至 | 说明 |
|------------|---------|--------|------|
| **GP10** | SPI1 SCK | PAW3395 SCLK | 时钟信号 |
| **GP11** | SPI1 MOSI | PAW3395 MOSI | 主机输出，从机输入 |
| **GP12** | SPI1 MISO | PAW3395 MISO | 主机输入，从机输出 |
| **GP13** | GPIO | PAW3395 NCS | 片选（低电平有效） |
| **GP14** | GPIO | PAW3395 MOTION | 运动中断（低电平有效） |
| **GP15** | GPIO | PAW3395 NRESET | 复位（低电平有效） |
| **3.3V** | 3.3V OUT | PAW3395 VDD | 电源 |
| **GND** | GND | PAW3395 GND | 地 |

> ⚠️ **注意**：PAW3395 是 3.3V 器件，请勿直接连接 5V。

**SPI 参数：**
- 波特率：500 KHz
- 模式：CPOL=1, CPHA=1 (Mode 3)
- CS 延时：1 μs
- 寄存器读写延时：10 μs

---

### 3. PS2 双轴摇杆

| Pico 2 引脚 | 引脚名称 | 连接至 | 说明 |
|------------|---------|--------|------|
| **GP26** | ADC0 | 摇杆 VRX | X 轴模拟输出 |
| **GP27** | ADC1 | 摇杆 VRY | Y 轴模拟输出 |
| **GP28** | GPIO | 摇杆 SW | 按键（按下时接地） |
| **3.3V** | 3.3V OUT | 摇杆 VCC | 电源 |
| **GND** | GND | 摇杆 GND | 地 |

**ADC 参数：**
- 分辨率：12 位 (0-4095)
- 参考电压：3.3V
- 中间值：约 2048（摇杆居中时）

---

### 4. 滚轮编码器

| Pico 2 引脚 | 引脚名称 | 连接至 | 说明 |
|------------|---------|--------|------|
| **GP20** | GPIO | 编码器 A 相 | 旋转脉冲 A |
| **GP21** | GPIO | 编码器 B 相 | 旋转脉冲 B |
| **GP22** | GPIO | 编码器 SW | 中键（按下时接地） |
| **3.3V** | 3.3V OUT | 编码器 VCC | 电源（如有） |
| **GND** | GND | 编码器 GND | 地 |

> 💡 **提示**：建议在 A/B 相引脚添加 10K 上拉电阻，或使用内部上拉。

## 📍 Pico 2 引脚分布图

```
                          Pico 2 (RP2350)
                         ┌───────────────┐
          (USB)          │               │
         ┌───┐           │  GP0      GP25 │  (板载LED)
         │   │           │  GP1      GP24 │
         └───┘           │  GP2      GP23 │
                         │  GP3      GP22 │  ← 编码器中键
  编码器A相 → GP10       │  GP4      GP21 │  ← 编码器B相
  编码器B相 → GP11       │  GP5      GP20 │  ← 编码器A相
  编码器CS  → GP12       │  GP6      GP19 │  ← 键盘 MOSI
  运动中断  → GP13       │  GP7      GP18 │  ← 键盘 SCK
  复位引脚  → GP14       │  GP8      GP17 │  ← 键盘 CS
  鼠标MISO  → GP15       │  GP9      GP16 │  ← 键盘 MISO
  摇杆X轴   → GP26       │  GND      GND  │
  摇杆Y轴   → GP27       │  3.3V     3.3V │
  摇杆按键  → GP28       │  VBUS     VSYS │
                         │  GND      GND  │
                         └───────────────┘
```

## ⚡ 电源说明

### 电源需求
- **工作电压**：3.3V（所有外设均为 3.3V）
- **最大电流**：约 100mA（所有外设同时工作）
- **供电方式**：
  - USB 供电（推荐）
  - VSYS 引脚供电（2-5V）

### 注意事项
1. ✅ 所有外设均使用 3.3V 供电
2. ✅ 所有 IO 引脚均为 3.3V 电平
3. ❌ 不要将 5V 信号直接连接到 GPIO 引脚
4. ❌ 不要从 3.3V 引脚抽取超过 300mA 的电流

## 🔧 接线检查清单

焊接/接线完成后，请逐项检查：

### 电源检查
- [ ] 3.3V 与 GND 之间没有短路
- [ ] 所有外设的 VCC 都连接到 3.3V
- [ ] 所有外设的 GND 都连接到 GND

### SPI 总线检查
- [ ] SPI0 SCK (GP18) 连接到键盘 74HC165 CLK
- [ ] SPI0 MISO (GP16) 连接到键盘 74HC165 QH
- [ ] SPI0 CS (GP17) 连接到键盘 74HC165 PL
- [ ] SPI1 SCK (GP10) 连接到 PAW3395 SCLK
- [ ] SPI1 MOSI (GP11) 连接到 PAW3395 MOSI
- [ ] SPI1 MISO (GP12) 连接到 PAW3395 MISO
- [ ] SPI1 CS (GP13) 连接到 PAW3395 NCS

### 其他外设检查
- [ ] PAW3395 MOTION (GP14) 连接正确
- [ ] PAW3395 NRESET (GP15) 连接正确
- [ ] 摇杆 X 轴 (GP26/ADC0) 连接正确
- [ ] 摇杆 Y 轴 (GP27/ADC1) 连接正确
- [ ] 摇杆按键 (GP28) 连接正确
- [ ] 编码器 A 相 (GP20) 连接正确
- [ ] 编码器 B 相 (GP21) 连接正确
- [ ] 编码器中键 (GP22) 连接正确

## 🐛 故障排查

### 设备不识别
1. 检查 USB 线是否正常
2. 检查 3.3V 供电是否正常
3. 检查固件是否正确烧录

### 键盘无响应
1. 检查 SPI0 接线（SCK/MISO/CS）
2. 检查 74HC165 级联是否正确
3. 用示波器观察 SCK 和 CS 信号

### 鼠标不动
1. 检查 SPI1 接线（SCK/MOSI/MISO/CS）
2. 检查 PAW3395 供电
3. 检查复位引脚是否正常

### 摇杆不准
1. 检查 ADC 接线
2. 确认摇杆居中时 ADC 值约为 2048
3. 在配置中调整死区和校准值

### 编码器跳数
1. 检查 A/B 相接线
2. 添加硬件滤波电容（0.1μF）
3. 在软件中增加消抖处理
