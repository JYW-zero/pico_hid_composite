# 编码器多模式与加速度文档

## 一、概述

本项目使用 **增量式旋转编码器**（带中键），采用双核架构：
- **Core1**：硬件读取 + 状态机解码 + 事件输入到处理器
- **Core0**：事件处理 + 多模式输出 + HID 报告生成

增强功能：
1. **多模式切换**：音量、滚动、缩放、亮度、自定义
2. **旋转加速度**：慢速精细，快速翻页
3. **去抖与方向判断**：4状态状态机 + 步长累积去抖
4. **模式切换**：中键短按循环切换模式
5. **模式状态持久化**：保存到配置 Flash，重启后保留

## 二、硬件架构

### 2.1 增量式编码器

```
RP2350 GPIO ──→ 编码器 A 相
RP2350 GPIO ──→ 编码器 B 相
RP2350 GPIO ──→ 编码器中键（上拉输入，低电平有效）
```

- A/B 相：正交编码，4 状态状态机解码
- 中键：按下切换模式
- 扫描周期：1ms（1000Hz）

### 2.2 双核架构

```
┌─────────────────────────────────────────────────────┐
│  Core1 (硬件扫描)                                    │
│  ┌──────────┐    ┌──────────────┐    ┌──────────┐ │
│  │ GPIO 读取│───→│ 4状态状态机  │───→│ 事件输入 │ │
│  │ (A/B/ SW)│    │ + 步长去抖   │    │ 到处理器 │ │
│  └──────────┘    └──────────────┘    └──────────┘ │
└──────────────────────────┬──────────────────────────┘
                           │ 事件队列（自旋锁保护）
┌──────────────────────────▼──────────────────────────┐
│  Core0 (业务处理)                                    │
│  ┌──────────┐    ┌──────────────┐    ┌──────────┐ │
│  │ 事件获取 │───→│ 模式判断     │───→│ HID 报告 │ │
│  │ (出队)   │    │ + 加速度     │    │ 生成     │ │
│  └──────────┘    └──────────────┘    └──────────┘ │
└─────────────────────────────────────────────────────┘
```

## 三、编码器处理器（middleware/encoder_processor）

### 3.1 多模式定义

| 模式 | 值 | 输出 | HID 报告 |
|------|---|------|---------|
| SCROLL | 0 | 鼠标滚轮 | Mouse Report (Report ID 2) |
| VOLUME | 1 | 音量增减 | Consumer Control (Report ID 3) |
| ZOOM | 2 | 缩放（Ctrl+滚轮） | Mouse Report + Keyboard |
| BRIGHTNESS | 3 | 亮度增减 | Consumer Control (Report ID 3) |
| CUSTOM | 4 | 自定义按键序列 | 预留 |

### 3.2 旋转加速度

**原理**：根据两次旋转事件的时间间隔，动态调整输出倍数。

| 时间间隔 | 加速度等级 | 倍数 | 说明 |
|---------|-----------|------|------|
| >200ms | 1X | 1 | 慢速精细 |
| 100-200ms | 2X | 2 | 中速 |
| 50-100ms | 5X | 5 | 快速 |
| <50ms | 10X | 10 | 极快翻页 |

**实现**：
- Core1 输入事件时携带时间戳
- 处理器计算与上次事件的时间间隔
- 根据间隔确定加速度等级和倍数
- 输出事件携带倍数信息

### 3.3 去抖与方向判断

**4状态状态机**：

```
状态转换表：[当前AB][上次AB] = 方向
  00: { 0, -1,  1,  0}
  01: { 1,  0,  0, -1}
  10: {-1,  0,  0,  1}
  11: { 0,  1, -1,  0}
```

**步长累积去抖**：
- 每次有效状态转换累积到 accum
- 累积达到 steps_per_tick（默认3）才输出一个有效 tick
- 防止抖动误触发

### 3.4 模式切换

**触发方式**：中键短按（<500ms）

**切换逻辑**：
- 短按：循环切换到下一个模式（SCROLL → VOLUME → ZOOM → BRIGHTNESS → CUSTOM → SCROLL）
- 长按（≥500ms）：预留，可配置其他功能

**消抖**：中键状态连续 3 次一致才确认（3ms@1ms 扫描）

### 3.5 模式状态持久化

**存储位置**：配置结构 `reserved3[0]`（1 字节，可存储 0-4）

**数据流**：
```
启动 → Core1 从配置读取模式 → encoder_processor_set_mode()
    ↓
模式切换 → encoder_processor_cycle_mode()
    ↓
Core0 检测模式变化 → config_save() → Flash
```

## 四、事件队列

**设计**：环形缓冲区，大小 16，自旋锁保护（双核安全）

**操作**：
- `event_queue_push()`：Core1 调用，入队事件
- `event_queue_pop()`：Core0 调用，出队事件

**溢出处理**：队列满时丢弃最旧的事件（覆盖）

## 八、优化功能详细说明（v2）

### 8.1 ZOOM 模式完整实现

**实现方式**：
1. 发送 Ctrl 按下的键盘报告（Modifier bit0 = Left Ctrl）
2. 发送鼠标滚轮报告（直接发送，不经过 g_wheel 累积）
3. 发送 Ctrl 释放的键盘报告

**键盘报告格式**（标准 6KRO）：
- byte[0] = Report ID (1)
- byte[1] = Modifier（bit0 = Left Ctrl）
- byte[2] = Reserved
- byte[3-8] = Key codes

### 8.2 加速度曲线可配置

**曲线类型**：

| 曲线 | 值 | 1x阈值 | 2x阈值 | 5x阈值 | 特点 |
|------|---|--------|--------|--------|------|
| 标准 | 0 | 200ms | 100ms | 50ms | 默认，平衡 |
| 慢 | 1 | 400ms | 200ms | 100ms | 更精细，需要更快旋转才能触发高倍 |
| 快 | 2 | 100ms | 50ms | 25ms | 更灵敏，轻微加速就触发高倍 |

**接口**：
- `encoder_processor_set_accel_profile(profile)` — 设置曲线
- `encoder_processor_get_accel_profile()` — 获取曲线

### 8.3 模式切换 LED 反馈

**实现方式**：
- 模式切换时触发 LED 快速闪烁（100ms 间隔）
- 闪烁次数 = 模式编号 + 1
  - SCROLL（0）：1 次
  - VOLUME（1）：2 次
  - ZOOM（2）：3 次
  - BRIGHTNESS（3）：4 次
  - CUSTOM（4）：5 次

**非阻塞实现**：
- 使用全局变量记录剩余闪烁次数和下次闪烁时间
- 在 `led_blinking_task` 中处理，不阻塞主循环
- 反馈期间暂停正常闪烁

### 8.4 CUSTOM 模式基础框架

**实现方式**：
- 顺时针旋转发送可配置的键码（默认：上箭头 0x52）
- 逆时针旋转发送可配置的键码（默认：下箭头 0x51）
- 发送按键按下 + 按键释放序列

**接口**：
- `encoder_processor_set_custom_keys(cw_key, ccw_key)` — 设置自定义键码
- `encoder_processor_get_custom_keys(&cw_key, &ccw_key)` — 获取自定义键码

**后续扩展**：
- 支持多键组合（如 Ctrl+C、Alt+Tab）
- 支持按键序列（宏）
- 支持修饰键配置
