# 功能清单 - Pico2 HID 复合设备

## 项目概述

基于 Raspberry Pi Pico 2 (RP2350) 的 USB HID 复合设备固件，支持 64 键 SPI 键盘、PAW3395 光学鼠标传感器、PS2 摇杆、滚轮编码器。采用六层架构设计，模块化、可测试、可维护。

- **主控芯片**: RP2350 (双核 ARM Cortex-M33)
- **开发语言**: C11
- **构建系统**: CMake + Ninja
- **SDK 版本**: pico-sdk 2.3.0
- **固件版本**: v0.2.0
- **最后更新**: 2026-08-14

---

## 一、硬件支持

### 1.1 64 键 SPI 键盘
- SPI0 接口，100kHz 波特率
- 8x8 矩阵，64 个按键
- 硬件消抖 + 软件消抖双重保障
- SPI 超时保护（100ms 超时，写 Flash 期间 Core1 被暂停）
- 支持 6KRO 按键上报

### 1.2 PAW3395 光学鼠标传感器
- SPI1 接口，500kHz 波特率
- 4 档 DPI 可切换：400 / 800 / 1600 / 3200
- 12 位有符号位移，正确符号扩展
- SPI 超时保护（500us 超时）
- 自旋锁保护多核访问
- 鼠标指针加速（阈值+线性加速算法）

### 1.3 PS2 双轴摇杆
- 12 位 ADC 读取（X 轴 ADC0，Y 轴 ADC1）
- 可配置死区（默认 100 ADC 计数）
- 死区外线性缩放到 -127~127
- 摇杆按键支持

### 1.4 滚轮编码器
- 4 状态状态机解码
- 可配置步长（steps_per_tick）
- 软件方向反转
- 中键支持（预留）

### 1.5 UART 调试串口
- 波特率 115200
- TX=GP0, RX=GP1
- 启动日志、配置信息、故障信息输出

## 二、USB HID 功能

### 2.1 HID Report ID 列表

共 19 个 Report ID：

| Report ID | 名称 | 方向 | 说明 |
|-----------|------|------|------|
| 1 | Keyboard | IN | 标准键盘报告（Boot Keyboard 协议） |
| 2 | Mouse | IN | 标准鼠标报告（5 键 + 滚轮） |
| 3 | Consumer Control | IN | 多媒体控制（音量、播放等） |
| 4 | Gamepad | IN | 游戏手柄 |
| 5 | Config Block 0 | IN/OUT | 配置块 0（偏移 0-62，63 字节） |
| 6 | Device Info | IN | 设备信息 |
| 7 | Control | OUT | 控制命令 |
| 8 | Config Block 1 | IN/OUT | 配置块 1（偏移 63-125，63 字节） |
| 9 | Config Block 2 | IN/OUT | 配置块 2（偏移 126-188，63 字节） |
| 10 | Key Stats 0 | IN | 按键统计块 0（键 0~15） |
| 11 | Key Stats 1 | IN | 按键统计块 1（键 16~31） |
| 12 | Key Stats 2 | IN | 按键统计块 2（键 32~47） |
| 13 | Key Stats 3 | IN | 按键统计块 3（键 48~63） |
| 14 | Macro Config | IN/OUT | 宏配置读写 |
| 15 | Perf System | IN | 性能监控 - 系统状态 |
| 16 | Perf Task | IN | 性能监控 - 任务统计 |
| 17 | Fault Info | IN | 错误日志 - 信息 |
| 18 | Fault Log | IN | 错误日志 - 读取日志 |

### 2.2 按键映射
- 两层映射：普通层 + Fn 层
- 64 键完整映射表，存储在 Flash
- 支持普通键、修饰键、Fn 键、多媒体键
- Fn 键位置可配置

### 2.3 多媒体键支持
- 音量加 / 音量减 / 静音
- 播放/暂停 / 上一曲 / 下一曲 / 停止 / 弹出
- 共 8 个常用多媒体键

### 2.4 DPI 切换
- 4 档 DPI 可切换：400 / 800 / 1600 / 3200
- DPI 设置保存到 Flash，断电不丢失
- 通过核间 FIFO 命令切换，规范的生产者-消费者模式

## 三、软件架构

### 3.1 六层架构
1. **Hardware 层**: pico-sdk 官方库（只读，不修改）
2. **Board 层 (BSP)**: 统一硬件初始化、引脚映射、配置存储
3. **Device 层**: 外设抽象驱动，零状态、可重入、多实例
4. **Middleware 层**: 通用中间件，跨模块复用
5. **Protocol 层**: USB HID 协议（描述符、报文、配置通道）
6. **App 层**: 纯业务逻辑，HID 报文组装、主状态机

### 3.2 双核架构 (Core0 + Core1)
采用生产者-消费者模式：
- **Core1 (生产者)**: 专门负责硬件扫描
  - PAW3395 传感器读取（2ms）
  - 编码器扫描（1ms）
  - 键盘扫描 + 消抖（5ms）
  - 摇杆读取（10ms）
  - 喂 DEVICE 层看门狗
  - 心跳计数器递增

- **Core0 (消费者)**: 负责 USB 业务和系统管理
  - USB HID 上报（1000Hz 回报率）
  - 按键映射、Fn 层处理
  - 配置管理、Flash 写入
  - 系统监控、看门狗巡检
  - Core1 健康诊断、自动恢复

### 3.3 核间通信
- **共享内存 + 自旋锁**: 安全传递硬件扫描数据
- **FIFO 命令通道**: 规范的命令/响应机制
  - SET_DPI: 设置 DPI
  - SET_ENCODER_REV: 设置编码器方向
  - SET_JOYSTICK_DZ: 设置摇杆死区
  - PAUSE / RESUME: 暂停/恢复扫描（Flash 写入用）
  - SLEEP: 进入低功耗休眠
  - PING: 心跳测试

## 四、系统可靠性

### 4.1 分层逻辑看门狗
- 三层架构：BOARD / DEVICE / APP
- 每层独立喂狗，任意层卡死都能检测到
- 逻辑超时 200ms，硬件看门狗 400ms（2 倍余量）
- 硬件看门狗作为最后防线
- 记录最后故障层，方便诊断

### 4.2 Core1 异常自动恢复
- 心跳检测：100ms 检测一次
- 连续 3 次（300ms）无心跳 → 判定 Core1 卡死
- 自动复位并重启 Core1，USB 连接不中断
- 重启前清空 FIFO 和共享数据，避免脏数据
- 临时帮喂 DEVICE 层看门狗，争取重启时间

### 4.3 频繁重启保护
- 滑动窗口：10 秒时间窗口
- 窗口内重启超过 5 次 → 禁用自动恢复
- 禁用后由硬件看门狗触发整机复位
- 避免设备进入"假活"状态（USB 连着但功能全挂）

### 4.4 统一故障处理
- 四级故障级别：INFO / WARN / ERROR / FATAL
- 统一记录、统一输出
- 方便调试和问题定位

### 4.5 SPI 超时保护
- 键盘 SPI：1000us 超时
- PAW3395 SPI：500us 超时
- 避免硬件异常时整个系统卡死

## 五、配置存储

### 5.1 Flash 双备份机制
- 配置存储在 Flash 最后 8KB
- A/B 两个扇区交替写入，每个 4KB
- 序列号判断最新版本
- 一个扇区损坏，另一个还能用
- 防止断电丢配置

### 5.2 配置项
- DPI 设置（400/800/1600/3200）
- 摇杆死区（ADC 原始值）
- 编码器方向（正常/反转）
- 64 键普通层映射表
- 64 键 Fn 层映射表
- 配置序列号
- CRC32 校验

### 5.3 版本迁移机制
- 配置版本号管理
- 支持旧版本配置自动迁移到新版本
- 向前兼容，升级固件不丢配置

### 5.4 Flash 写入双核同步
- 写入前暂停 Core1 扫描
- 写入后恢复 Core1 扫描
- 弱回调函数实现，分层清晰
- 避免 Flash 写入时 Core1 访问硬件冲突

## 六、低功耗管理

### 6.1 功耗等级
- **ACTIVE**: 正常运行，全速
- **SLEEP**: Sleep 模式，CPU 停止，外设运行，~5.9mA
- **DORMANT**: Dormant 模式，振荡器停止，~3.3mA

### 6.2 运行模式
- **有线模式**: USB 已挂载，跟随 USB 挂起进入 Sleep
- **无线模式**: USB 未挂载，无操作超时进入 Dormant

### 6.3 唤醒源
- PAW3395 MOT 引脚（鼠标移动）
- 编码器 A/B 相（旋转）
- 摇杆按键
- USB 恢复信号

### 6.4 双核低功耗
- Core0 发 SLEEP 命令给 Core1
- Core1 进入 WFE 休眠
- Core0 进入低功耗模式
- 唤醒后 Core0 发 SEV 事件唤醒 Core1

## 七、鼠标指针加速

### 7.1 算法
经典阈值 + 线性加速：
- 低速（< 5 计数/帧）：1:1 精准，适合精细操作
- 中高速：线性增加加速系数
- 上限：最大 3 倍加速，避免过快失控

### 7.2 配置
- 开关：可通过宏定义开启/关闭
- 阈值：开始加速的最低速度
- 加速度：每超过阈值 1 计数增加的系数
- 最大加速：系数上限

## 八、USB 配置协议

通过 Vendor HID 报告（Report ID = 5）与上位机通信，64 字节报告。

### 8.1 命令列表

| 命令码 | 命令 | 功能 |
|--------|------|------|
| 0x01 | GET_VERSION | 获取固件版本字符串 |
| 0x02 | READ_CONFIG | 分块读取配置（offset + length） |
| 0x03 | WRITE_CONFIG | 分块写入配置，收完自动写 Flash |
| 0x04 | GET_STATS | 获取状态统计 |
| 0x05 | RESET_CONFIG | 恢复默认配置 |

### 8.2 状态统计
- 键盘扫描次数
- PAW3395 读取次数
- 编码器扫描次数
- 摇杆读取次数
- 错误计数
- Core1 复位次数

### 8.3 上位机工具
- 	ools/config_test.py: Python 测试脚本
- 依赖：pip install hidapi
- 可验证所有命令，作为 PC 配置工具的起点
